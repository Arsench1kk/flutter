# Practice 07 — A Form That Validates Itself

Open this folder in IntelliJ IDEA, select `lib/main.dart` as the entry point, and run the app. From the repository root, choose the shared **Practice 07** configuration.

The form demonstrates field-level validation with `Form` and `TextFormField`, keyboard focus and scrolling, a group dropdown, date picker, agreement checkbox, and a responsive success summary.

Run `flutter analyze` from this folder to check the Dart source.
