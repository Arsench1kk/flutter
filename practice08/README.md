# Practice 08 — A Little of Everything

Open this folder in IntelliJ IDEA, select `lib/main.dart` as the entry point, and run the app. From the repository root, choose the shared **Practice 08** configuration.

The reading list recaps Dart models and collection functions, reactive filtering, adaptive row layout, navigation with returned values, and a validated add-book form.

Run `flutter analyze` from this folder to check the Dart source.
