# Practice 12 — Survive a Restart

Open the repository in IntelliJ IDEA, choose **Practice 12**, select an Android or iOS device, and run. The settings, sign-in and offline list can also be demonstrated on macOS.

```sh
flutter pub get
flutter run
```

Use a sample email such as `student@example.com` and any password with at least eight characters. The sign-in is a simulation and the user records come from JSONPlaceholder.

- **Settings** contains dark mode, the city filter, the profile and sign out.
- **Profile** supports choosing a photo and taking one on a mobile device with a camera.
- **Users** loads from the server and shows a banner when displaying the saved list offline.
- **User details** opens the email, phone and website in the corresponding apps.

See [NOTES.md](NOTES.md) for package verdicts, storage and permission answers, and the verification record.
