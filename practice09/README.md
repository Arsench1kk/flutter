# Practice 09 — Put It High, Subscribe Low

A small bookshop app used to compare lifted cart state with a `ChangeNotifier` exposed through Provider. The app has a Books screen, a cart badge, and a Cart route. It progresses through the five assignment levels; the final version keeps the cart model independent of widgets and lets each UI component subscribe only to the values it displays.

Open this folder in IntelliJ IDEA and run `lib/main.dart`. Level 1 is preserved in Git history in the commit named `lifted`.
